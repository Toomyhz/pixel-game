# Pixel Game - Legacy
`[Última versión de documento 18/08/2026]`
## Descripción
Tienda virtual de videojuegos, primeros inicios en desarrollo web.

## Tech Stack
- Python 3.12
- Django 4.2.2
- SQLite
- Pillow
- Sweetify
- WhiteNoise

## Requerimientos
- Python 3.12*
> *La compatibilidad con versiones posteriores aún no ha sido verificada.

# IMPORTANTE
Este proyecto carece de documentación formal. Fue desarrollado hace años y no recibió más actualizaciones. Las próximas versiones traeran cambios grandes a la plataforma + docs.

En el commit [`6a0c32f`](https://github.com/Toomyhz/pixel-game), se cambió la base de datos a SQLite debido a que las credenciales de la antigua base de datos fueron expuestas y posteriormente dadas de baja.   
Actualmente, el proyecto mantiene una dependencia que ya no es necesaria para la configuración actual:   
`"mysqlclient==2.2.0"`  

Esta dependencia será revisada y eventualmente eliminada durante el proceso de mantenimiento del proyecto.
